# Contributing

A repository with its own `CONTRIBUTING.md` (KMP, MADE and AXLR Bots have one)
follows it. Everywhere else:

- Use GitHub issues for bugs and feature requests. Report vulnerabilities
  privately, as [SECURITY.md](SECURITY.md) describes.
- Start from the current `main` and open the pull request against `main`.
  Keep the change focused.
- Say what changed, why, how you validated it, and any contract or migration
  impact.
- Run the checks the repository's README and CI run, and report their exact
  outcome. Never present a stub, mock or no-op as proof of real execution.
- A change in behaviour updates the documentation that describes it.
- Contributions are accepted under the repository's license.

Conduct in every project space follows the
[Code of Conduct](CODE_OF_CONDUCT.md).
