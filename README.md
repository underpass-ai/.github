# .github

Shared organization profile and community health files for Underpass AI.

The public organization homepage is rendered from [`profile/README.md`](./profile/README.md).

[`SECURITY.md`](./SECURITY.md), [`CONTRIBUTING.md`](./CONTRIBUTING.md) and
[`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md) apply to every public repository
that does not publish its own.

[`scripts/apply-metadata.sh`](./scripts/apply-metadata.sh) holds the
organisation and repository metadata: descriptions, homepages and topics. It
prints the `gh` commands and changes nothing unless it is run with `--apply`.
